# 01. Analysis 

## 1. 프로젝트 개요

### 1.1 프로젝트 목적

Seatsurfing 예약 관리 시스템을 대상으로 사용자 및 관리자 관점에서 주요 기능과 동작을 분석

기능 분석을 통해 서비스의 기본 구조와 기능 간 연관성을 파악하고, 이를 기반으로 테스트 케이스를 설계 진행

### 1.2 테스트 대상

| 구분 | 내용 |
|---|---|
| 테스트 대상 | Seatsurfing 예약 관리 시스템 |
| 사용자 유형 | 일반 사용자, 관리자 |
| 주요 분석 범위 | 로그인, 공간 예약, 예약 조회, 사용자 및 예약 관리 |
| 테스트 환경 | Docker 기반 로컬 환경 |
| 분석 기준 | 실제 서비스 이용을 통한 기능 및 화면 동작 확인 |

## 4. 주요 기능 간 연관성

서비스 내 주요 기능 간 데이터 및 상태 연관성을 확인하기 위한 항목이다.

| 연관 기능 | 확인 대상 |
|---|---|
| 예약 화면 ↔ My Bookings | 예약 생성 결과 및 예약 정보 정합성 |
