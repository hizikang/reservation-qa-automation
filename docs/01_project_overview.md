# 01. Project Overview

## 목적
Seatsurfing을 테스트 대상으로 삼아 예약 업무 흐름의 품질을 검증하고 QA 자동화 역량을 보여준다.

## 역할 구분
- 기존 프로젝트: Seatsurfing 애플리케이션 (테스트 대상)
- 본 프로젝트: 테스트 전략, 테스트 케이스, 자동화 코드, 결함 분석 및 결과 보고서

## 검증 대상 후보
- 사용자 인증
- 리소스 및 예약 가능 시간 조회
- 예약 생성/취소
- 관리자 예약 관리
- 사용자/관리자 간 데이터 상태 일관성

기능 존재 여부와 세부 규칙은 실제 실행 및 공식 문서 확인 후 확정한다.
