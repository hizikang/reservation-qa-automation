# Test Environment

This directory documents how to run the Seatsurfing System Under Test (SUT).

## Important
Do not copy the Seatsurfing application source into this QA repository by default.
Use the official Seatsurfing repository and its current deployment documentation:

- https://github.com/seatsurfing/seatsurfing

Before creating a Compose file here:
1. Check the official deployment instructions for the version you intend to test.
2. Confirm required environment variables, ports, database configuration, and persistent volumes.
3. Record the exact Seatsurfing version or image tag used.
4. Keep secrets and local environment files out of Git.

The Compose configuration will be added after the SUT version and official deployment method are verified.
